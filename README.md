## About OdaaMart

OdaaMart is a comprehensive multi-vendor e-commerce platform built with Flutter, offering:

- **Food Delivery** — Order from your favorite restaurants
- **Grocery Shopping** — Fresh produce and household essentials
- **eCommerce** — Wide range of products from multiple vendors
- **Pharmacy Services** — Medicines and health products delivered
- **Parcel Delivery** — Send and receive packages securely
- **Ride Sharing** — Get around town safely
- **Service Booking** — Book services from verified providers

## Brand Story

The **Odaa tree** (*Cordia africana*) is an iconic shade tree native to Ethiopia and the Oromia region. 
It symbolizes freedom, peace, and cultural heritage. Under its broad canopy, communities gather for 
discussion, resolution, and celebration.

OdaaMart brings these same values to e-commerce:
- 🌿 **Growth** — Like the mighty Odaa, we help businesses grow
- 🤝 **Community** — Connecting vendors and customers
- ☮️ **Trust** — Building reliable marketplaces
- 🏛️ **Heritage** — Honoring tradition while embracing innovation

## Tech Stack

- **Framework**: Flutter 3.44.6+ (Dart)
- **State Management**: GetX
- **Architecture**: Clean Architecture (Feature-first)
- **Backend**: Laravel + Firebase
- **Real-time**: Pusher Channels

## Getting Started

\```bash
# Install dependencies
flutter pub get

# Run the app
flutter run

# Build for web
flutter build web --release
\```
